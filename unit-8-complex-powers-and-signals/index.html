Powers & transformations

A power changes both parts

Raise the modulus to the power. Multiply the angle by that power.

(reiθ)n = rneinθ

This is de Moivre’s rule in Euler form. Here r > 0 and n is an integer.

For example, find (2eπi/3)² in Cartesian form.

  1. 2² = 4 and 2 × π/3 = 2π/3.
  2. So (2eπi/3)² = 4e2πi/3.
  3. 4(cos(2π/3) + i sin(2π/3)) = −2 + 2√3i.

Negative powers follow the same rule

A reciprocal inverts the modulus and reverses the angle.

(2e2πi/3)−1
  1. The modulus becomes 2−1 = ½. The angle becomes −2π/3.
  2. ½e−2πi/3 = ½(cos(−2π/3) + i sin(−2π/3)).
  3. The result is −¼ − (√3/4)i.
Why does the angle change sign?

A number multiplied by its reciprocal gives 1. Their moduli multiply to 1 and their angles add to 0, modulo 2π.

A negative power requires a non-zero complex number.

    Useful details

    For ω>0, the period is 2π/ω. The phase φ is an angle. The horizontal shift is −φ/ω.

    The argument command uses the correct quadrant. If the combined complex number is zero, the signals cancel and there is no unique phase or fundamental period.

    For sine signals, first use sin u=cos(u−π/2), then follow the cosine method.

    Useful mathematics

    Use radians. Keep exact values unless an approximation is requested.

    reiθ = r(cos θ + i sin θ)

    (reiθ)ⁿ = rⁿeinθ,   r > 0, n ∈ ℤ

    For a principal argument, use −π < Arg(z) ≤ π. Zero has no argument.

    Add real and imaginary components separately. Choose the angle using the quadrant.

    A non-zero signal Acos(ωt+φ) with ω>0 has period 2π/ω.

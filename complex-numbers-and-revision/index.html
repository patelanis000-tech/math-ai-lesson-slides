Phasor practice

A shared rotation

For two signals with the same angular frequency, what can you factor out?

Aei(ωt+α) + Bei(ωt+β)
= (Aeiα + Beiβ)eiωt

Find the fixed sum first:

Z = Aeiα + Beiβ = Reiφ
Reveal the worked solution

For cosine, take the real part:

A cos(ωt+α) + B cos(ωt+β)
= R cos(ωt+φ)

For sine, take the imaginary part and keep the same R and φ.

T = 2π/|ω|   (ω ≠ 0, R > 0)
Interpret / checkThe common angular frequency stays unchanged. Constant baselines add separately. If Z = 0, there is no unique phase.

Hodder Worked Example 6.14, p.205; Oxford Investigation 8 and Example 10, pp.364–365; Haese Example 23, p.292.

A compound-growth threshold

A balance of RM6000 earns 4% compound interest once per year. There are no deposits or withdrawals.

Let n count completed years, so n is a nonnegative integer.

  1. Find the balance after 8 years.
  2. Find the first end-of-year balance that is at least RM9000. State the year number.

Model: A(n) = P(1 + r)n. You may use logs, a numerical solver or a graph.

A hint, if you need it
The continuous threshold solves 6000(1.04)n = 9000. Does that answer the completed-year question?
Reveal the worked solution

Every solution in the interval

A model for water height is

h(t) = 3 + 2 sin(πt/6),   0 ≤ t ≤ 12

t is hours after midnight and h is measured in metres.

  1. State the amplitude, midline and period.
  2. Find every time in this interval when h(t) = 4.5 m.

Check radian mode and the full domain. A graph can check the number of crossings.

A hint, if you need it
Solve sin(πt/6) = 0.75. An inverse-sine calculation gives only one starting angle.
Reveal the worked solution

Amplitude 2 m. Midline h = 3 m. Period 12 h.

α = arcsin(0.75)
t₁ = 6α/π ≈ 1.619679263 h
t₂ = 6(π − α)/π ≈ 4.380320737 h

Approximately 1.62 h and 4.38 h after midnight.

Interpret / checkTwo crossings occur in the specified interval. Decimal hours are not hours-and-minutes notation.
Optional extension

For how long is the model at least 4.5 m?

Check

Mixed revision

A triangle in three dimensions

A = (1, 0, 2),   B = (3, 1, 4)
C = (0, 2, 3)

Coordinates are measured in metres.

  1. Find the vectors AB and AC.
  2. Find angle BAC in degrees.
  3. Find the area of triangle ABC.

u · v = |u||v| cos θ
Triangle area = ½|u × v|

A hint, if you need it
Both side vectors must start at A. The magnitude of a cross product gives the parallelogram area.
Reveal the worked solution
AB = (2, 1, 2),   AC = (−1, 2, 1)
AB · AC = 2,   |AB| = 3,   |AC| = √6
∠BAC = arccos[2/(3√6)] ≈ 74.2°
AB × AC = (−3, −4, 5)
Area = ½√50 = 5√2/2 ≈ 3.54 m²
Interpret / checkThe triangle uses half the parallelogram area. Reversing the cross-product order changes its direction, but not the area.
Optional extension

Find a unit normal to the plane of the triangle.

Check

(−3, −4, 5)/√50, or its negative. Its dot product with each side vector is zero.

Formula reference

Complex forms and integer powers

z = r(cos θ + i sin θ) = reiθ
zn = rneinθ   (z ≠ 0 for n < 0)

Same-frequency addition

Z = Aeiα + Beiβ = Reiφ
R = √(x² + y²),   φ from the quadrant of x + iy
T = 2π/|ω|   (ω ≠ 0, R > 0)

Use the real part for cosine and the imaginary part for sine. Add constant baselines separately. The zero phasor has no defined argument.
